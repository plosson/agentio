AgentIO

A CLI for LLM agents to interact with communication services

Quick Install

macOS and Linux
Windows
curl -LsSf https://agentio.work/install | sh
iwr -useb https://agentio.work/install.ps1 | iex

To update to the latest version:

agentio update

What is AgentIO?

AgentIO is an open-source command-line interface designed for LLM agents to interact with communication services like Gmail, Telegram, and Google Chat. It features multi-profile support and encrypted credential storage.

Features

  • Gmail: search, read, send, reply, archive emails
  • Telegram: send messages to channels
  • Google Chat: send messages via webhook or OAuth
  • JIRA: create issues, search, add comments
  • Slack: send messages via webhooks
  • Multi-profile support for multiple accounts
  • Encrypted credential storage (AES-256-GCM)
  • Self-update capability

Alternative Installation
