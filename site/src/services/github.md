## What you can do

- Install `AGENTIO_KEY` and `AGENTIO_CONFIG` as repo secrets in one command
- Drive scheduled agent workflows via GitHub Actions

## Setup

```sh
agentio github profile add
agentio github install <owner/repo>
```
